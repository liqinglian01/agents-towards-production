# 使用 LangGraph 与 Bright Data 构建强大的网页抓取 Agent 🕷️

## 概述

构建能够搜索、提取并分析任意网站数据的智能网页抓取 Agent。将 LangGraph 的 ReAct 框架与 Bright Data 业界领先的网页抓取能力相结合，打造用于数据采集、市场研究和竞争分析的生产级系统。

## 你将学到什么

- **ReAct Agent 架构**：为复杂的 Web 任务构建会推理、会行动的 Agent
- **智能 Web 搜索**：创建能够选择最优搜索策略的 Agent
- **结构化数据提取**：从主流平台（Amazon、LinkedIn、社交媒体）提取数据
- **通用网页抓取**：借助先进的爬虫检测绕过能力处理任意网站
- **生产环境优化**：错误处理、速率限制和性能调优

## 教程

### **[MCP 集成：web_scraping_agent.ipynb](./web_scraping_agent.ipynb)**
使用 Bright Data 的 MCP 服务器构建复杂的网页抓取 Agent，包含 60 多个专用工具，涵盖浏览器自动化与特定平台提取器。

### **[LangChain 集成：langgraph_integration.ipynb](./langgraph_integration.ipynb)**
使用 Bright Data 原生 LangChain 工具创建精简的网页抓取 Agent，实现快速开发和轻松集成。

## 快速开始

1. **注册 Bright Data** - 每月可免费获得 5k 次请求
2. **获取 LLM API 访问权限** - MCP 使用 OpenRouter，LangChain 使用 Google AI Studio
3. **选择你的路径** - 想要快速上手就用 LangChain，需要高级能力就用 MCP
