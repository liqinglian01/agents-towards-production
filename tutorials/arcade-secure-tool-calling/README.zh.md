# 🚀 使用 Arcade.dev 的多用户 Agent 教程

## 概览

构建真正能在生产环境中为多用户服务的 AI Agent。学习使用 Arcade.dev 实现安全认证、安全控制和真实服务集成——弥合本地演示与生产就绪系统之间的差距。

## 你将学到什么

- **多用户认证**：为 Gmail、Slack 和 Notion 设置 OAuth2 流程
- **生产架构**：构建可扩展到单用户演示之外的 Agent
- **安全控制**：为敏感操作添加 human-in-the-loop 审批
- **真实服务集成**：以适当的认证方式把 Agent 连接到外部 API
- **安全最佳实践**：实现生产就绪的安全措施

## 教程

### **[完整教程：multiuser-agent-arcade.ipynb](./multiuser-agent-arcade.ipynb)**
逐步构建越来越复杂的 Agent：
1. **基础聊天 Agent** - 使用 LangGraph 的简单对话式 AI
2. **带工具的 Agent** - 安全访问外部 API 的 AI
3. **生产级 Agent** - 具备安全控制和多服务协调能力的完整系统

## 技术栈

- **LangGraph** - Agent 编排与状态管理
- **Arcade.dev** - 认证与安全的 API 访问
- **OAuth2** - 安全的用户授权

## 适用人群

希望构建能在现实世界中为多用户服务、而不仅仅是酷炫演示的 AI Agent 的开发者。
