# 使用 Contextual AI 构建生产级 RAG Agent

## 概述

本教程展示如何使用 Contextual AI 的托管平台构建检索增强生成（RAG）agent。你将学习为金融文档分析创建 RAG 流水线，这有助于简化生产级系统的构建过程。

## 你将学到什么

- **文档处理**：解析带表格、图表和结构化内容的金融文档
- **RAG Agent 创建**：使用自定义指令构建和部署 agent
- **查询处理**：与你的文档知识库进行自然语言交互
- **性能评估**：用于评估和改进结果的测试框架

## 教程

**[完整教程：contextual_tutorial.ipynb](./contextual_tutorial.ipynb)**

本教程带你完成一个金融文档分析 RAG agent 的创建，涵盖 datastore 配置、文档摄入、agent 配置和性能评估。
